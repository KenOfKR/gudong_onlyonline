古董局中局 v10.8.21 安裝說明

1. 將整個 ZIP 解壓到新的資料夾，不要直接覆蓋 v10.8.20。
2. 建議使用 Node.js 18 或更新版本執行測試。
3. 在專案根目錄執行：
   node tests/run-v10-8-21-regressions.js
4. 啟動本機 HTTP：
   python -m http.server 8000
   瀏覽器開啟 http://localhost:8000/
5. 若測試語音辨識，需使用支援 SpeechRecognition 的瀏覽器及允許麥克風權限；建議實際部署時使用 HTTPS。
6. 點擊「公開語音字幕」開始收音，再點一次停止；只有 final 辨識文字會同步到房間。
7. 點擊「語音操作」開始收音，說出完整命令，例如「鑑定狗」、「傳牌給藍色玩家」、「投兩票給狗」。辨識後先確認，再執行。可以說「取消操作」取消。
8. 此版 STT 不保證離線；瀏覽器不支援時仍可用鍵盤與原有操作介面。

注意：本版字幕使用現有 Firestore 房間文件同步，不使用 Realtime Database；只同步文字，不傳音訊。請勿在公開字幕模式說出私人資訊。語音辨識及雙瀏覽器同步仍需在實際部署環境人工驗收。
