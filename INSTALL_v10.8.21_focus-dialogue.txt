v10.8.21 Focus-Driven Dialogue 補丁安裝說明
============================================================

1. 先備份目前線上版本與 Firebase 測試房間資料。
2. 將完整 ZIP 解壓到新的資料夾，不要直接覆蓋唯一的工作副本。
3. 本 ZIP 保留應用程式版本字串 10.8.21；這是同版本的焦點導向台詞補丁，不是規則升版。
4. 先在本機靜態伺服器測試：
     python -m http.server 8000
   再開啟：
     http://localhost:8000
5. 進入 solo 模式，特別測試：
   - 有人自稱老朝奉／藥不然時，AI 是否聚焦技能與傳牌時序追問。
   - AI 被點名時，是否先回應對方，而不是照常念票數報告。
   - AI 有實際查驗資料時，是否明確表達查驗與票向的關聯。
   - 不相關的第二條查驗或預測是否不再硬塞進同一段發言。
6. 執行回歸測試：
     node tests/run-v10-8-21-regressions.js
7. 驗收通過後，再將完整專案部署到 GitHub Pages。

注意：本補丁未完成 Gemini 線上端點及真實瀏覽器語音端到端測試。不要以 Node 測試通過取代實際瀏覽器驗收。
