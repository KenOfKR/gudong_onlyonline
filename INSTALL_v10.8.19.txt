古董局中局 v10.8.19 安裝說明

1. 先備份目前 v10.8.18 專案資料夾。
2. 將 gudong_v10.8.19_candidate.zip 完整解壓到新的資料夾；此包保留原專案素材與圖片。
3. 使用 Node.js 18 或更新版本可執行自動測試（本次測試使用 Node.js v22.16.0）。
4. 建議使用本機 HTTP 伺服器開啟，不要直接 file:// 開啟 index.html：

   python -m http.server 8000

   然後瀏覽 http://localhost:8000/

5. 在專案根目錄執行完整回歸：

   node tests/run-v10-8-19-regressions.js

個人標記：
- 標記僅保存在當前瀏覽器／裝置的本機儲存空間。
- 不會同步給房間其他玩家，也不會提供給 AI。
- 以對局 gameId 和目前使用者分隔；不同局不共用標記。
- 清除瀏覽器該網站資料會清除個人標記。

若從 v10.8.18 升級，請直接使用本版完整 ZIP 解壓至新目錄，確認正常後再自行替換舊版本；不要把本版檔案零散覆蓋到仍在運行的房間資料夾。
