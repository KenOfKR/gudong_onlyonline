# 古董局中局 v10.8.14｜角色推斷、承諾延續與投票意圖分層

> 本版以 v10.8.13 完整版為底版，集中強化公開證據下的鄭國渠隊友推斷、老朝奉／藥不然的鄭國渠後驗、角色偽裝可行性與跨輪承諾、投票意圖分層及自然發言整理。遊戲規則不變；公開主張與真實票單仍可分離，棄票仍合法，傳牌與發言順序仍分開處理。

## v10.8.14 主要變更

1. **角色後驗與隊友推斷**：新增獨立 `pZheng`，不與 `pEvil`、`pLao` 混為一談；鄭國渠可依前兩輪公開共同錯誤主張與共同投向已揭露贗品的行為，推斷最多兩名隊友。判斷依據限於公開發言、票單與已公開 rank2。
2. **角色偽裝延續與可行性**：公開假身分跨輪延續；只有明確說明改口才可切換。依角色能力及可用證據評估假跳可行性，避免無能力支撐的角色偽裝。
3. **藥不然偷襲目標保護**：候選評分新增 `pZheng` 高可信保護懲罰；公開集火需有 `pEvil > 0.60` 才會被策略跟隨。
4. **鄭國渠早期盲認訊號**：前兩輪加入小比例分票訊號；只在沒有明確硬承諾且有公開線索時使用，不把公開發言或票向鎖死。
5. **投票意圖分層**：重複強調某獸首為真只形成軟性意圖；「我應該會投」不視為硬承諾。硬承諾、軟意圖、公開呼籲與實際票單分開稽核。
6. **老朝奉末輪策略**：若好人得分已高、且自己的公開／私人可見後驗仍找不到高可信鄭國渠，進入較積極的末輪姿態。
7. **終局評分與發言**：鑑人加入票型與技能時序交叉訊號；勝率估計使用較寬的不確定區間，明確標註為啟發式。發言移除重複模板與內心分析語句，保持自然、短句。

## 重要限制

`pZheng`、偷襲風險、終局勝率與策略姿態仍是推理／決策用的後驗或啟發式，不是實戰校準機率。完成固定種子配對 A/B、大樣本與真人盲測前，不宣稱本版勝率提升。Mock Firestore 測試也不等同正式 Firebase 多裝置驗收。
