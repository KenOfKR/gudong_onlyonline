# 古董局中局 v10.8.21

本版以 v10.8.20 完整專案為基礎，加入角色互換辨識、公開語音字幕及經確認的語音操作。既有遊戲規則、傳牌順位、查驗、投票與終局計分規則不因語音功能而改變。

## 本版變更

1. **公開角色聲稱降權**：明確自稱特殊角色僅作為未驗證聲稱；角色判斷仍須比對技能、行動及時序，不可單憑自稱確認身分。
2. **老朝奉／藥不然角色互換稽核**：把兩位玩家互相認領兩個壞人特殊角色的公開說法連成待核對模式。這只會形成質詢線索，不會單憑互換宣稱判定誰是壞人或誰是真角色。
3. **自然問句解析**：擴充「說清楚、講清楚、回答、說一下」等問句辨識，避免 AI 已提問但系統未記錄被問對象。
4. **語音操作**：新增語音操作模式，可解析鑑定、老朝奉擾亂、鄭國渠封鎖、藥不然偷襲、方震陣營查驗、傳牌、投票、棄票與終局指認。辨識只產生待確認意圖；確認時再次檢查遊戲階段、角色、目標及籌碼，並呼叫原有 Engine API。
5. **公開語音字幕**：新增公開字幕模式。只有完整辨識結果會寫入目前回合的 `voiceTranscripts`，透過現有 Firestore 房間文件同步；不新增 Realtime Database，不傳原始音訊。
6. **AI 讀取字幕**：AI 決策時暫時將公開字幕投影為可解析的對話記錄，決策後即還原原本 `speeches`，不推進正式發言順位，也不污染正式陳詞紀錄。文字字幕可被同房間玩家及 Bot 讀取，請勿用此功能傳送私人內容。
7. **字幕生命週期**：每輪最多保留 32 段、每人至少間隔 1.5 秒；所有最終指認完成並進入 gameover 後清除字幕暫存。原始音訊不會被此功能保存。
8. **目標選取**：語音目標解析支援房間內真人與 Bot 玩家，名稱或顏色不唯一時拒絕執行，要求更明確的目標。

## 技術限制與重要說明

- **語音辨識使用瀏覽器 `SpeechRecognition` / `webkitSpeechRecognition`，語言設定為 `zh-TW`。** 這不是 Whisper，也不是 Transformers.js；不保證離線，辨識是否可用取決於瀏覽器與平台服務。
- 若瀏覽器不支援 SpeechRecognition，遊戲仍可用文字操作；目前版本沒有整合 WebGPU Whisper 或 Python／CUDA 本地 STT 微服務。
- 本版只同步最終字幕文字，沒有語音通話。若要真人互相傳送聲音，需另外設計 WebRTC。
- 房間同步沿用專案現有 Firestore transaction + `onSnapshot`。字幕存在房間文件的每輪陣列，並非 Realtime Database 子節點。
- 現有房間同步使用用戶端房間資料封裝與混淆；本次沒有新增獨立伺服器端字幕安全規則。公開字幕不是私密頻道，也不應視為端對端加密。
- 語音操作在辨識完成後顯示待確認項目；語音「確認執行」或按鈕確認後才送出。遠端字幕只供 AI 理解，不會進入本機 CommandInterceptor。

## 啟動

建議 Node.js 18+；網頁請經 HTTP/HTTPS 開啟，不要使用 `file://`：

```bash
python -m http.server 8000
```

瀏覽器開啟 `http://localhost:8000/`。
