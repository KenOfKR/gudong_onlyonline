# 古董局中局 v10.8.16｜發言歸因、漸進偽裝與票型協調

> 本版依 v10.8.15 實戰紀錄，優先修正「引用內容誤當本人主張／號召／投票承諾」，並進一步改善角色偽裝、角色後驗、壞人票型協調及 Learning 因果紀錄。遊戲規則維持不變：公開主張與實際票單可以分離、允許分票與合法棄票，傳牌與發言順序仍分開處理。

## v10.8.16 主要變更

1. **發言歸因**：本人主張、本人號召、本人硬承諾及他人引用主張分離；引用「鼠假、投鼠」不再污染目前發言者最後的羊真／投羊立場。
2. **語意一致性**：加入本人矛盾及內部分析術語稽核；允許有策略目的的公開號召與實際投票不同。
3. **角色偽裝**：不再無故每輪自報角色；先以行為鋪陳，必要時才正式聲稱。好人遭角色施壓時也可低機率採取反反心理。
4. **角色辨識**：自稱角色是弱證據，不能直接當成身分證明或排除條件；角色機率與壞人陣營機率分開。
5. **壞人票型**：依公開票勢估計替代贗品是否更有機會進前二，允許保留表面票向但實際轉票或拆票。
6. **Learning**：保存本人號召、引用來源、決策當時票勢、最終票數及是否進前二，分開處理決策前支持與全輪最終支持。
